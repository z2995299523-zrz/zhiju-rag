# 知据 v1.5.0 整改验收

## 原问题和验证路径

| 顺序 | 使用场景 | 改动和验收方式 |
|---|---|---|
| 1 | 查制度时返回无关预算，或指定部门后查到全单位 | 默认自动分类，保留手动模式。连接器按字段别名、实体和可绑定的限定条件构造实际请求。检查发送给接口的条件和返回记录，不确定的限定条件需要澄清。 |
| 1 | 金额失真，缺页仍给合计，业务失败被写成零 | 绑定十进制原值。成功状态、返回行数、已知总量、分页和可加指标分开。高精度金额、0 条成功、本页 1 条且总数 75、业务失败、两项目合计 2,000 万元均有回归。 |
| 1 | 续问丢失项目和指标，重试后跳错历史分支 | 在对应用户的父轮分支继承已确认的条件，当前输入优先。测试同一项目从 2026 年的 75% 续问 2025 年，得到 68%；浏览器测试重试旧轮、切换分支和刷新。 |
| 1 | 数字都出现过，但指标顺序、肯否或因果与原文不符 | 段落校验原文、数值、字段及其关系。引用保留原文区间，按段落高亮。数值互换、否定反转、将背景写成原因、同源两段各引不同句均有针对性测试。 |
| 2 | 同一行的值与标题、期间或单位分离 | Excel、CSV、TSV、Word、PowerPoint、HTML 与 Markdown 表格按表区/行处理。检查纽约人口表的 F5、G5 及其年份表头，宽表再检查末端列和同一行的主体。 |
| 2 | 原件的显示值与底层值不同，或隐藏内容、嵌图被误用 | 保存 Excel 底层值、可识别的显示格式、公式和缓存情况。默认排除隐藏区，警告可回到原位置。PDF 按页记录文字层、OCR 和未提取页，图片按帧记录覆盖。 |
| 2 | 节名、日期，或章节标题、条款分离 | 文档分块携带所属记录、路径和标题。以香港假期同一事件的名称和开始日期、日历级时区和历法、PPT 的具体教学指令验证。 |
| 2 | 同名资料互相覆盖；升级规则后仍复用旧索引 | 资料按来源和文件名分组，再用原件摘要、解析器版本、设置区分版本。用保存的原件重建、新旧引用定位以及恢复旧版时解析调用为零，检验切换的可逆性。 |
| 2 | 上传繁忙只能重传整个批次，或无法确认哪些内容入库 | 预检和提交返回逐文件结果。实测三文件同批的成功、繁忙和永久失败，只有暂时失败项重试。确认前库中为零份；已成功项和永久失败原因在重试后仍可见。 |
| 2 | 原件对照打开错 JSON 行，宽表看不到命中列 | JSON 按转义 Pointer 找到原字节范围，JSONL 保留物理行号。Excel 支持分组翻列和按字段定位。用单行 JSON、超出前 24 行的对象和 90 列表内的 CH3 检查。 |
| 3 | 检索只有封面、标题或错误同名实体，或语义排序失败难查 | 同时使用原文和结构上下文，保护精确实体及字段命中。管理员可查看候选、重排名次、实际入选的原文，查看分批向量排序的结果、缓存和失败原因，另可用固定诊断文本探测并发。 |
| 3 | 回答中断后不清楚发生在哪一步 | 执行记录区分上游首个增量、首个可核验段落、完成、验证拦截和中断。只有合法终态完成归档，页面可保留未完成的文字并重试。 |
| 3 | JSON 与 SSE 入口的续问/幂等行为不同，多进程重复读业务数据 | 两入口共用执行和归档。同一用户同一请求由共享 SQLite 工作区的文件锁串行执行，验证两个应用实例同时发起时上游仅执行一次，历史正文与流式结果一致。 |
| 3 | 业务快照嵌套后评测误判，或同一行业术语在不同工作区被混用 | 评测核对原始响应摘要、记录路径和数值精度。行业可独立配置文档用词、实体/参数别名、指标及其单位和允许操作。制造、仓储的“流转单”分别检索各自声明的定义。 |

导入规则、异常清单和覆盖定义见[标准化导入流程](import-formats.md)。业务系统适配示例见[响应与指标口径](业务接口响应与指标口径.md)。可运行的回归包括[结构和覆盖](../tests/test_import_formats.py)、[版本和并发](../tests/test_import_lifecycle.py)、[业务查询](../tests/test_business_queries.py)、[事实与依据校验](../tests/test_grounded_claims.py)和[阅读器](../tests/test_reader_api.py)。

## 2026 年 11 月 23 日实测

- **文件入口。** 通过应用上传接口验证全部 18 个扩展名，含启用本地 OCR 后的五种图片扩展名。每个有效样本检查了非空分块、原件摘要、下载字节和原件定位；随后用损坏的同名文件复试，18 份都被退回，原活动版本均可继续读取。
- **既有资料。** 使用保存的原件重建 14 份资料，最终索引有 9,034 个活动分块。10 份无警告；4 份需人工复核，分别是全为文本的 CSV 表头、Word 绘图、PPT 非文本对象及 PDF 嵌图。文件级复核标记和每页 OCR 覆盖可分别查看。
- **宽表和记录隔离。** 在 390 像素宽的浏览器中定位到 90 列表中的 `CH3 = 72814`。一行分成多个片段后，按主体仍能检索到第 27 列。两台资产的编号在父级、冷却压力在子对象，分别询问 `BX-17` 和 `BX-27` 得到 78 和 42，引文分别落在 `/0/metrics` 和 `/1/metrics`。
- **唯一原值回退。** 完整的上游响应未通过文档事实校验、且还没有发出正文时，简单取值题可根据确切主体、字段和期间定位唯一原值。用原始人口表和香港日历、可控模型响应分别复验 JSON 和流式问答入口，芝加哥 2021 年估计人口得到 2,704,101，2026 年 10 月 19 日的假期得到“重阳节翌日”。主体重复、字段重复、条件未匹配、断线或已经发出部分正文时保持原处理。[取值回归](../tests/test_record_lookup.py)
- **浏览器。** 实际触发解析槽繁忙、重试、重建、回退和打开历史依据。回退没有重新解析文件。另用可控上游测试停止、切换会话取消、传输中断和重试；已收到的段落保留，重试成功后只归档一次。打开和关闭依据弹窗时对话区横坐标相同。
- **业务与独立样例。** 科研财务模板 15/15、制造模板 2/2。另用海洋观测的独立样例检查跨站串值、章节混用和资料不足，关闭模型时首轮 1/5；修复后以相同 5 题经 HTTP 重测为 5/5。该结果用于定向回归。

### 公开文档问答

在 11 份带已核对 SHA-256 的公开文档上，使用冻结的 37 题、自动路由和实际 SSE 接口。每题新会话，只计各轮首次请求。对话模型为 `qwen3.8-flash`，向量模型为 `qwen3.7-text-embedding-flash`。一题须同时答对所问事实并得到实际引用支持；资料不足题可凭正确拒答得分。

| 指标 | 本次完整一轮 |
|---|---:|
| 完全正确 | 31/37（83.8%）。旧版同题为 21/37（56.8%） |
| 可答题答对且引文支持 | 28/34 |
| 资料不足题正确拒答 | 3/3 |
| 回答形式合格 | 31/37 |
| 固定困难子集的内容、形式 | 12/13、11/13；这 13 题包含在 37 题内 |
| 完成归档且正文、来源可回放 | 32/37 |
| 有实际原文锚点的引用 | 30/30 |

32 次成功回答均在 `done` 前收到正文；其中跨年公报题有两段正文分别到达，时间为 26.594 秒和 27.328 秒，27.641 秒收到 `done`。这组时间取自 HTTP 客户端。其余成功请求在本轮各有一次正文输出。另一次完整试跑为 32/37，云模型输出和耗时存在波动。

全量当轮共有六项未答对。芝加哥人口、香港日历元信息和两道人口普查题在生成校验阶段中断。一道粮食产量题选到其他年份的公报后错误拒答，一道气候公报题上游超时。另有一道假期日期题事实正确，但正文直接呈现 `20260217`，自然表达未过。芝加哥题暴露了正确表行与两段无关 HTML 同时入选后阻断唯一记录提取的问题，随后的补丁按文档分组，并保留跨文档的唯一性校验。该补丁的专项验证与上述完整一轮分别计分。

最终构建在相同文库独立补测两道受影响题，2/2 正确并可回放。芝加哥人口 2,704,101 引用工作表 `A7:G7`；香港日历的 `Asia/Hong_Kong` 和 `GREGORIAN` 引用 `/vcalendar/0`。这两次实际请求由模型正常完成。另以原始三条入模证据重放芝加哥题，核实唯一记录回退也能得到同一值；有第二份冲突台账时拒绝回退。

在升级后的本机工作台上，又用 Chrome 提交跨年公报题。页面第 16.386 秒绘制 2023 年答案，第 17.086 秒绘制包含 2024 年答案的第二段，第 19.420 秒进入完成状态。实际业务接口两轮分别返回 75% 和 68%；配置中的向量接口并发接收两批各 8 条诊断文本，均返回 1024 维向量。原库 81 条历史与 14,324 个旧分块逐条对照升级前备份一致。

## 验收边界

- 用公开原件检验文档检索与问答。问答得分需要同时判断主体、期间、数值、口径和引用；导入成功、检索命中或引用能打开都不能单独证明答对。
- 业务数值来自演示预算接口和受控测试接口。接入客户数据时，要用已确认的参数、粒度、分页约定、单位和一组有标准答案的查询重新验收。
- 来源名称用于区分资料版本。文档和来源的读取沿用工作区权限。需要部门级文档授权时须配置相应的隔离工作区或另行设计访问策略。
- 复杂视觉版式、扫描金额、公式缓存是否最新、自然语言推断仍需要人工对照。向量排序处理入选候选；低词面重合的资料仍可能在候选阶段漏掉。

| 实测中仍出现的问题 | 下一步可验证的处理办法 |
|---|---|
| 指定年份的统计题召回了另一年公报 | 区分“报告发布年”和“指标发生年”；在同系列公报中分别保留目标年份的候选，再按指标核对。用同名指标、不同年度及跨年比较三类问题验收。 |
| 普查文字段包含多个限定条件，引文校验拦截整段 | 将列举、例外和因果拆成独立结论，每项核对对应的原句；保留能证实的分项。互换例外省份或误引四舍五入原因的反例仍须被拦截。 |
| PDF 长题触发上游超时 | 通过诊断区分等待上游和校验耗时，按问题分项提供短的可核验段落；以同一原页的实测输出和错误状态验收。 |
| 正确日期偶尔以八位原串进入中文正文 | 限定在类型明确的日期字段，只规范答案中的日期显示，保留引文原始字面值。编号、批次和没有有效年月日的八位串须保持原样。 |
